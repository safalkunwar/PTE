# Task-Specific Study Resources

Every PTE Academic task type now includes dedicated study materials, scoring strategies, recommended templates, common mistakes to avoid, and sample breakdowns. These resources are accessible directly inside the active practice session via the **Study Guide & Tips** button in the header bar.

## Catalog Scope
- Covers all 20 official PTE task types across Speaking, Writing, Reading, and Listening.
- Provides actionable scoring templates and structural frameworks (e.g., 3-part Describe Image framework, Essay structural template, dictation shorthand rules).
- Fully tested with Vitest specifications and verified against the production build.

## Access and Coverage Update

The same study guide is now available before launch from every expanded task card on the Practice page and during the active PracticeSession. Section-specific aliases such as Reading & Writing Fill in the Blanks and Listening Multiple Choice resolve to the correct shared guide. Personal Introduction also has a dedicated guide that clearly states it is unscored and should be used only to settle into the test environment.

The full regression suite now passes with 186 tests and the production build remains clean.
